# 公式识别与问答系统

基于Qwen2.5-VL和Qwen2.5-Coder的公式提取、代码生成与问答系统。该系统可以从图像中提取数学公式，将公式转换为Python代码，构建知识库，并支持公式相关的问答。

## 功能特点

1. **公式提取**：从图像中自动识别并提取数学公式
2. **公式代码化**：将提取的公式转换为可执行的Python函数
3. **知识库构建**：基于提取的公式和代码构建向量知识库
4. **公式问答**：根据用户查询找到相关公式并计算结果
5. **一键处理**：一次性完成从图像到问答的全流程处理

## 系统要求

- Python 3.7+
- Node.js 14+
- npm 或 yarn

## 快速开始

### 1. 安装依赖

首先安装Node.js依赖:

```bash
npm install
```

然后安装Python依赖:

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

复制环境变量示例文件:

```bash
cp .env.example .env
```

编辑`.env`文件，填入您的API密钥和其他配置信息。

### 3. 启动系统

使用npm启动系统:

```bash
npm run dev
```

系统将启动交互式命令行界面，引导您配置服务端口和其他选项，然后启动Web界面。

## 使用流程

1. 将需要识别的公式图像放入`images`目录
2. 访问Web界面 http://localhost:7864 (或您配置的端口)
3. 按照标签页顺序操作:
   - 公式提取：从图像提取公式
   - 公式代码化：生成Python代码
   - 知识库构建：构建数据库
   - 公式问答：进行公式相关问答
4. 或者直接使用"一键处理流程"标签页完成全流程处理

## 目录结构

- `images/`: 存放要识别的公式图像
- `knowledge_base/`: 存放提取的公式、代码和知识库
- `scripts/`: Node.js启动脚本
- `*.py`: Python核心功能模块
